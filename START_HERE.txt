COMMUNITY LIBRARY MANAGEMENT SYSTEM

HOW TO RUN
1. Extract this ZIP.
2. Open the extracted Community_Library_Management_System folder in VS Code.
3. Choose Terminal > New Terminal.
4. Run: npm install
5. Then run: npm run dev
6. Open the address printed in the terminal, usually http://localhost:5173
